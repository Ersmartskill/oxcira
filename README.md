# إعلان أوكسيرا التفاعلي

نسخة جاهزة للرفع على GitHub Pages — آخر تحديث: 24 نوفمبر 2026.

## النشر
1. فك ضغط الملف.
2. ارفع محتويات المجلد إلى جذر مستودع GitHub، بحيث يكون index.html في جذر المستودع، مع مجلد assets وجميع الملفات الأخرى.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم فرع main ومجلد / (root)، واحفظ.
5. افتح رابط الموقع الذي يعرضه GitHub بعد اكتمال النشر.

لا ترفع ملف ZIP وحده؛ ارفع الملفات بعد فك الضغط. لا تحتاج النسخة إلى تثبيت حزم أو عملية بناء أو قاعدة بيانات.

## التعديلات المضمنة
- نغمة الآيفون المرفقة وتسجيلات المكالمة العربية.
- ربط المنصة والمتصفح بالموقع العربي الرسمي.
- روابط Instagram وX وLinkedIn وواتساب الرسمية.
- القنوات تفتح Linktree؛ استبدال TikTok غير المدرج في Linktree بأيقونة استشارة تفتح صفحة Linktree التي تحتوي الحجز.
- الملاحظات والإعدادات تحفظ على جهاز الزائر في المتصفح.

## تعديل المحتوى
بيانات المنصة وروابط التواصل في config.js، والسلوك في app.js، والتصميم في style.css.
يبدأ الصوت بعد ضغط «ابدأ التجربة»، وفق قيود تشغيل الصوت في المتصفحات.
الصور والخطوط والصوت مرفقة داخل assets. راجع assets/AUDIO_CREDITS.md لملاحظات الصوت.

تحديث إصلاح الروابط: تفتح الروابط الخارجية مباشرة دون طلب تبويب منبثق جديد، لتوافق أفضل مع معاينة الجوال. تم اختبار النقر وظهور الموقع الرسمي وLinktree في المتصفح.
